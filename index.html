Pengaturan

Otomatis: alamat api.anthropic.com memakai format Claude asli, alamat lain (DeepSeek, OpenAI, ModelRouter) memakai format OpenAI /chat/completions. Tiap model di Daftar model bisa punya Base URL dan key sendiri.
Disimpan di browser ini saja, tidak ikut ke GitHub. Jangan isi di komputer umum.
Aturan pembuatan file Word, Excel, PPT, dan membaca gambar sudah otomatis ikut terkirim, tidak perlu diisi di sini.
Kalau file panjang terpotong, naikkan (Claude: 16000 atau lebih). DeepSeek maksimal 8192.
Isi jika ModelRouter punya endpoint /images/generations. Kosong = Mode gambar membuat SVG lewat model chat.
Daftar model
Tambahkan beberapa model. Model yang terkena limit otomatis dilewati dan pesan dikirim lewat model berikutnya di daftar.
Kosongkan Base URL dan key untuk memakai yang di atas. Claude langsung: model claude-sonnet-4-6, Base URL https://api.anthropic.com/v1. DeepSeek: model deepseek-chat, Base URL https://api.deepseek.com/v1.
